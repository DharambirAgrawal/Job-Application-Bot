# Job Application Bot

Highlight a job description, get back a tailored cover letter (or resume) — generated by Gemini and dropped straight into your own DOCX template.

## What it does

Job Application Bot is a Chrome extension paired with a Flask API. Select a job posting's description on any webpage, and the extension sends it to the backend, which combines it with a saved summary of your resume, prompts Gemini to write role-specific content, and merges the result into a DOCX template you provide — preserving your template's formatting instead of generating a document from scratch. You get back a ready-to-download `.docx` (or `.pdf`) cover letter or resume in seconds.

The repo also includes an early-stage Next.js dashboard intended as a web-based alternative to the extension; it currently uses placeholder data and is not yet wired to the API.

## Features

- **In-page cover letter generation** — select text on any site, click "Generate Cover Letter," and get a tailored draft without leaving the page
- **Resume tailoring** — the same flow can rewrite specific placeholders (summary, bullets, company name, etc.) in a resume template using ATS-friendly, job-relevant language
- **Template-preserving output** — content is inserted into your own `.docx` template via placeholder substitution (`python-docx`), so formatting, fonts, and layout stay intact
- **DOCX and PDF export** — preview the generated document in-browser and download it as DOCX or convert it to PDF (via Playwright/Chromium on the backend)
- **Prompt-injection–resistant prompts** — job description and resume text are wrapped in explicit BEGIN/END data markers and the prompts instruct Gemini to ignore any instructions embedded in that content
- **Profile storage** — resumes, cover letter templates, and generated summaries are stored in Supabase Storage (S3-compatible) and reused across requests
- **Draggable, auto-showing UI** — a floating action button that appears automatically when enough text is selected, built as a Manifest V3 content script

## Tech Stack

**Extension** (`extension/`) — React 19, Vite, Tailwind CSS v4, Chrome Extension Manifest V3, `mammoth` (DOCX → HTML preview)

**API** (`api/`) — Python, Flask, `google-generativeai` (Gemini), `python-docx`, `PyPDF2`, Playwright (HTML → PDF), boto3 (Supabase S3-compatible storage), Gunicorn, Docker

**Dashboard** (`client/`) — Next.js 15, React 19, TypeScript, Tailwind CSS (early-stage / not fully integrated)

## Getting Started

### Prerequisites

- Node.js 18+ and npm
- Python 3.12+
- A Gemini API key ([Google AI Studio](https://aistudio.google.com/app/apikey))
- A Supabase project with an S3-compatible storage bucket (for storing your resume summary and DOCX templates)

### 1. Backend (API)

```bash
cd api
pip install -r requirements.txt
playwright install chromium   # only needed for the HTML-to-PDF endpoint
```

Create an `api/.env` file:

```bash
GEMINI_API_KEY=your-gemini-api-key
SUPABASE_ENDPOINT=https://your-project-id.supabase.co/storage/v1/s3
SUPABASE_BUCKET=your-bucket-name
SUPABASE_ACCESS_KEY=your-supabase-access-key
SUPABASE_SECRET_KEY=your-supabase-secret-key
API_KEY=a-shared-secret-your-clients-will-send-as-x-api-key
```

Run it:

```bash
python index.py
# or, in production:
gunicorn index:app --bind 0.0.0.0:5000
```

Before generating anything, upload a `coverletter.docx` (and/or `resume.docx`) template to the `templates` folder via `POST /api/upload-template`, and a plain-text resume summary via `POST /api/upload-summary` (or upload a resume through `POST /api/upload`, which summarizes it with Gemini automatically).

### 2. Extension

```bash
cd extension
npm install
npm run build
```

Then in Chrome: go to `chrome://extensions`, enable Developer Mode, click "Load unpacked," and select `extension/dist`.

Point the extension at your backend by editing the `baseUrl` values in `extension/src/config/index.js`, and set your `x-api-key` value in `extension/environment.js` (gitignored — create it if it doesn't exist):

```js
export const VITE_JOB_ASSISTANT_API_KEY = "your-shared-api-key";
```

### 3. Dashboard (optional)

```bash
cd client
npm install
npm run dev
```

## Usage

1. Load your resume summary and DOCX templates into the backend (see above).
2. On any webpage, highlight a job description (80+ characters).
3. The floating action menu appears automatically — click **Generate Cover Letter** or **Generate Resume**.
4. Preview the result and download it as DOCX or PDF.

If no text is selected when you trigger generation, a modal lets you paste a job description manually.

## How it works

The backend keeps prompts and document generation strictly separate from formatting:

1. Raw text (resume or job description) is cleaned — normalized whitespace, stripped boilerplate ("Page X of Y", "Confidential"), truncated to a safe length for the model.
2. The cleaned text is wrapped in explicit `BEGIN ... END` markers inside the Gemini prompt, with instructions to treat that content as data only and ignore anything inside it that looks like an instruction.
3. Gemini is asked to respond with a JSON object whose keys are the exact placeholder tokens used in your DOCX template (e.g. `<%COMPANYNAME%>`, `<%PARAGRAPH1%>`, or, for resumes, `<%SUMMARY CH200 LN3%>` where `CH`/`LN` encode character and line limits).
4. That JSON is parsed and used to replace the matching placeholders directly inside your uploaded `.docx` file with `python-docx`, so the original template's fonts, spacing, and layout are untouched.
5. The finished document is streamed back to the extension for preview and download; an optional Playwright-powered endpoint converts HTML content to PDF.
